== 1. ACTORS (/actors)

GET /actors
Описание: список актёров с пагинацией и поиском.
Параметры query:

limit (int, default 20)

offset (int, default 0)

name (str | None) — поиск по имени
Возвращает:
{ count, items: [{actor_id, name}] }

GET /actors/{actor_id}
Описание: детали актёра.
Параметры: actor_id (str)
Возвращает: {actor_id, name, birth_year, bio, photo_url}

GET /actors/{actor_id}/films
Описание: фильмы данного актёра.
Возвращает: {count, items: [{film_id, title}]}

POST /actors
Описание: создать актёра.
Тело запроса: JSON
{ actor_id?, name, bio?, birth_year?, photo_url? }
Возвращает: {status:"created", actor_id}

PATCH /actors/{actor_id}
Описание: обновить данные актёра.
Тело запроса: JSON (name?, bio?, birth_year?, photo_url?)
Возвращает: {status:"updated"}

DELETE /actors/{actor_id}
Описание: удалить актёра.
Возвращает: {status:"deleted"}

== 2. AUTH (/auth)

POST /auth/register
Описание: регистрация пользователя.
Форм-данные или query: username, email, password
Возвращает: {msg:"OK", id}

POST /auth/login
Описание: вход.
Формат: OAuth2PasswordRequestForm
form.username = email
form.password = password
Возвращает: {access_token, token_type:"bearer"}

GET /auth/me
Описание: информация о текущем пользователе по токену.
Возвращает: {id, username, email}

== 4. FILMS (/films)

GET /films/top
Возвращает: топ-5 по рейтингу
{count, items:[{id,title}]}

GET /films/newest
Возвращает: новые фильмы
{count, items:[{id,title}]}

GET /films/{film_id}
Возвращает: базовые данные фильма
{id,title,year,description,runtime,poster_url}

GET /films/{film_id}/actors
Возвращает: актёров фильма
{count, items:[{actor_id,name}]}

GET /films/{film_id}/genres
Возвращает: жанры фильма
{count, items:[{genre_id,name}]}

GET /films/{film_id}/ratings
Возвращает: список оценок
{count, items:[{user_id,rating}]}

GET /films/{film_id}/rating
Возвращает: средний рейтинг
{film_id, avg_rating}

GET /films/{film_id}/details
Возвращает: полные данные фильма (жанры, актёры, статистика)
{ film_id,title,release_year,description,runtime,poster_url, genres[], actors[], stats{} }
