Запустить cmd в папке project

Удалите виртуальное окружение: папку venv
Создайте новое виртуальнео окржение:
python -m venv venv

Перейти в виртуальное окружение:
venv\Scripts\activate

Установить зависимости
pip install -r requirements.txt


Настроить PostgreSQL.
Убедиться, что сервер PostgreSQL запущен.
